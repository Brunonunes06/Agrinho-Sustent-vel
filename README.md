# Agrinho Sustentável

## Projeto: Calculadora de Consumo de Água

Este projeto usa HTML semântico, CSS responsivo e JavaScript funcional para calcular o consumo diário e mensal de água. O objetivo é ajudar estudantes a entender o impacto do uso de água em casa e incentivar práticas de economia.

### Funcionalidades
- Formulário responsivo para entrada de dados
- Cálculo do consumo de água em banhos, descargas, lavagens e jardim
- Resultado com consumo diário, consumo mensal e economia possível
- Recomendações simples de sustentabilidade

### Estrutura
- `index.html` - conteúdo semântico e organizado
- `style.css` - estilo moderno, responsivo com cores naturais
- `script.js` - lógica de cálculo e interação do formulário

### Como usar
1. Abra `index.html` no navegador
2. Preencha os campos com os dados da sua casa
3. Clique em "Calcular consumo"
4. Veja o resultado e as dicas de economia

### Observações
- O projeto inclui a tag `agrinho` no `index.html` para atender ao requisito de identificação.
- O código foi estruturado para ser claro, funcional e compatível com o tema de sustentabilidade.
